# No Meat Proxy

Режим наставника для тех, кто хочет сохранять навык программирования и системного мышления при работе с AI.

**Ты пишешь код и выбираешь архитектуру. AI помогает рассуждать, оценивает решения и показывает, что стоит доучить.**

English: an explicitly enabled coding mentorship skill. You write the code and own architectural decisions; the assistant gives guidance, reviews your choices, and reports learning gaps. Activation, deactivation, code requests, one-time implementation permission, and learning reports work by intent in any language the model understands. No Russian passphrase is required. Instructions are maintained in Russian; responses use your language.

## Возможности

- Код в чате — только по прямому запросу.
- Изменение проекта — только после явного разового разрешения выполнить конкретную задачу за тебя, на любом языке.
- Подробные объяснения в чате, без учебных комментариев в коде.
- Оценка каждого предложенного решения: качество кода, расширяемость, чистота, правильность.
- Справка по доступной переписке: сильные стороны, темы для изучения, упражнения и критерии освоения.
- Явное включение и выключение. Разовое разрешение на реализацию не выключает режим.
- Мультиязычные команды, ответы и справки: язык можно менять по ходу разговора.

## Установка

[Скачай ZIP](https://github.com/Exzik-dev/no-meat-proxy/archive/refs/heads/main.zip) и распакуй его или используй GitHub → Code → Download ZIP. Скопируй папку **`skills/no-meat-proxy` целиком** в каталог скиллов своего агента. Не копируй только SKILL.md: в agents/openai.yaml задано явное включение для Codex.

Репозиторий также можно клонировать:

```sh
git clone https://github.com/Exzik-dev/no-meat-proxy.git
cd no-meat-proxy
```

Для Codex стандартный каталог — `~/.codex/skills`. Если используется собственный `CODEX_HOME`, выбирай каталог `skills` внутри него. Для агентов с поддержкой общего каталога Agent Skills можно использовать `~/.agents/skills`; проверь правила своего агента. Не устанавливай две копии с одинаковым именем.

Пример для PowerShell из корня распакованного репозитория, при стандартной конфигурации Codex:

```powershell
New-Item -ItemType Directory -Force -Path "$HOME/.codex/skills" | Out-Null
Copy-Item -LiteralPath ./skills/no-meat-proxy -Destination "$HOME/.codex/skills/no-meat-proxy" -Recurse
```

Для macOS/Linux из корня распакованного репозитория:

```sh
mkdir -p ~/.codex/skills
cp -R skills/no-meat-proxy ~/.codex/skills/
```

Команды рассчитаны на первую установку. Если папка уже существует, сначала сравни версии; не копируй новую внутрь старой. Открой новый сеанс агента, чтобы он обнаружил установленный скилл.

## Использование

Включи режим сообщением:

> $no-meat-proxy

Затем, например:

> Хочу спроектировать хранение заказов. Мой вариант — список в памяти. Помоги оценить.

AI объяснит последствия и оценит доступные свойства идеи. Если кода нет, он не должен придумывать оценку качества реализации.

> Покажи код небольшого примера.

Это разрешает пример в чате, но не редактирование проекта.

> Сделай за меня, разрешаю: реализуй согласованную функцию проверки заказа.

Это разрешает указанную реализацию с подробным разбором. Неопределённые архитектурные решения остаются за тобой. После выполнения снова действует режим наставника.

> Справка: что мне доучить по нашей работе в этом режиме?

Справка использует доступную историю. Для нескольких чатов передай их фрагменты или предыдущие справки. История не выгружается и не сохраняется автоматически.

> Выключи no-meat-proxy.

## Любой язык, одинаковые правила

Русская фраза «сделай за меня, разрешаю» — пример, а не обязательный пароль. Команды распознаются по смыслу на любом языке, который понимает модель. Можно смешивать языки и менять их во время чата; это не сбрасывает режим и не расширяет разрешение.

| Действие | English | Español | 日本語 |
|---|---|---|---|
| Включить | Enable no-meat-proxy | Activa no-meat-proxy | no-meat-proxyを有効にしてください |
| Выключить | Disable no-meat-proxy | Desactiva no-meat-proxy | no-meat-proxyを無効にしてください |
| Пример в чате | Show me a code example | Muéstrame un ejemplo de código | コード例を見せてください |
| Выполнить конкретную задачу | I explicitly authorize you to add the agreed function to sum.py | Te autorizo a añadir la función acordada a sum.py | 合意した関数をsum.pyに追加することを許可します。 |
| Справка | What should I study next based on this chat? | ¿Qué debería estudiar según este chat? | このチャットをもとに、次に何を学ぶべきか教えてください。 |

Это примеры, а не список поддерживаемых языков. Включение через `$no-meat-proxy` доступно независимо от языка; можно также явно попросить включить или выключить режим наставника, если понятно, о каком режиме идёт речь.

Просьба показать код разрешает только ответ в чате. Для реализации требуется явное согласие на самостоятельное выполнение и конкретный объём задачи. «Продолжай», “go ahead”, отрицания, цитаты и просьбы перевести фразу сами по себе разрешения не дают. Если намерение или язык непонятны, помощник уточнит смысл и сохранит текущие ограничения. Понятное разрешение не требует повторения по-русски.

## Ограничения

Скилл — инструкции для AI, а не техническая блокировка инструментов. Соблюдение зависит от модели и среды; системные правила и разрешения среды остаются в силе. В других агентах файл agents/openai.yaml может не поддерживаться, поэтому явная активация также описана в самом SKILL.md.

Баллы оценивают конкретное решение при известных требованиях, а не общий уровень человека. Справка не доказывает освоение темы без самостоятельной практики.
